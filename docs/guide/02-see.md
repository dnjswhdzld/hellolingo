# 2. 보기. 내 문장이 영어로

![노트북 위에 말풍선 셋이 떠 있습니다. 주황 말풍선은 Fix, 초록 말풍선은 the null check, 보라 말풍선은 in the login handler라고 적힌 카드를 듭니다. 같은 색 실이 화면 속 같은 색 조각으로 이어집니다.](images/see.jpg)

유진은 작은 쇼핑몰의 화면을 만드는 개발자입니다. 오늘은 장바구니에 수량 버튼을 붙입니다.

## 첫 카드

유진이 Claude에게 일을 시킵니다.

```
장바구니에서 수량 바꾸는 버튼 만들어줘
```

입력창 위에 "영어로 옮기는 중…"이 잠깐 나옵니다.

![입력창 위의 상자에 "영어로 옮기는 중…"이 흐리게 나와 있습니다.](images/see-1-pending.png)

곧 카드가 나옵니다. Claude는 그동안에도 일을 합니다.

![카드에 영어 문장 "Create a button to change the quantity in the cart."와 한국어 문장이 같은 색 조각으로 나와 있습니다. 맨 아래 줄은 "Create a button — 버튼을 만들다"입니다.](images/see-2-card.png)

## 카드 읽는 법

- **첫째 줄.** 내 문장을 영어로 쓴 것입니다.
- **둘째 줄.** 내가 쓴 한국어입니다.
- **같은 색은 같은 뜻입니다.** "만들어줘"와 "Create"가 같은 색입니다. 이 문장에서는 부탁하는 말 "Create"가 맨 앞에 옵니다.
- **`•` 줄.** 다시 쓸 만한 핵심 표현입니다. 이 표현이 노트에 모입니다. 하루에 모으는 수에는 한도가 있습니다. [3장](03-collect.md)에서 다룹니다.

## 다음 일을 시키면

유진이 이어서 시킵니다.

```
수량이 0이 되면 장바구니에서 빼줘
```

새 카드가 준비될 때까지 지난 카드가 남아 있습니다. 맨 위에 흐린 글씨로 "다음 문장 옮기는 중…"이 붙습니다. 지금 보이는 카드가 지난 문장의 것이라는 뜻입니다.

![지난 카드 위에 "다음 문장 옮기는 중…"이 흐리게 붙어 있습니다.](images/see-3-next-pending.png)

곧 새 카드로 바뀝니다.

![새 카드에 "Remove it from the cart when the quantity becomes 0."이 나와 있습니다.](images/see-4-next-card.png)

## 짧은 답장에는 카드가 없습니다

유진은 버튼을 키우고 테스트를 돌린 뒤 "좋아 커밋해줘"라고 답합니다. 10자보다 짧은 말에는 카드를 만들지 않습니다. 그래서 바로 앞 카드가 그대로 남습니다.

![Claude가 커밋을 마쳤고, 카드에는 바로 앞 프롬프트인 "테스트 돌려서 다 통과하는지 확인해줘"가 남아 있습니다.](images/see-5-short-reply.png)

## 긴 프롬프트는 한 문장만

프롬프트가 여러 문장이면, 주된 부탁 한 문장만 카드에 옮깁니다. 붙여 넣은 로그나 코드도 빼고 옮깁니다. [5장](05-english.md)에서 예를 봅니다.
