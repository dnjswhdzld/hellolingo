# 7. 개발자가 아니어도

![노트북 화면에 색 줄이 있는 표가 떠 있습니다. 그 앞에서 말풍선 셋이 흩어진 빈 카드를 가지런한 줄과 칸으로 정리합니다.](images/everyone.jpg)

민은 혼자 온라인 옷 가게의 광고를 맡은 마케터입니다. 코드를 쓰지 않고, Claude에게 광고 성과 정리를 맡깁니다.

## 데이터 고르기

```
광고 문구 CSV에서 클릭률 1% 아래인 것만 골라줘
```

카드는 개발 일이 아니어도 똑같이 나옵니다. "pick only the ones"(~만 골라줘)처럼, 다른 일에도 쓸 말을 모읍니다.

![Claude가 클릭률이 1%보다 낮은 광고 문구 5개를 표로 보여 줍니다. 아래에 카드와 퀴즈가 있습니다.](images/everyone-1-pick.png)

## 문구 쓰기

```
고른 것마다 새 문구 3개씩 써줘. 30자 넘지 않게
```

두 문장 중 주된 부탁인 "고른 것마다 새 문구 3개씩 써줘."만 옮겼습니다.

![Claude가 문구마다 새 문구를 3개씩 썼습니다. 카드에는 "Write 3 new phrases for each one you picked."가 있습니다.](images/everyone-2-write.png)

## 저장하기

```
결과를 새 CSV로 저장해줘
```

![Claude가 새 CSV 파일을 저장했습니다. 카드에는 "Save the results to a new CSV."가 있습니다.](images/everyone-3-save.png)

개발자가 아니어도, Claude에게 일을 시키는 문장은 매일 씁니다. 그 문장이 그대로 영어 공부 재료가 됩니다.
